# 算法说明

## 光照分析

输入固定为 `uint8 H×W×3 BGR`。灰度采用 OpenCV BGR2GRAY。

- 平均亮度：μ = ΣY / N，范围 0–255。
- 直方图：256 个灰度桶，计数总和等于像素数。
- 欠曝比例：Y < 30 的像素比例；过曝比例：Y > 240。
- 对比度：灰度标准差，不等同于局部人脸可识别性。
- 光照不均匀度：4×4 网格的块均值标准差 / max(全局均值, 1)。
- 清晰度：Laplacian(Y) 方差；噪声也可能增大该值，因此不将其独立视为质量保证。
- 逆光线索：图像中心一半区域均值与外圈均值的差。

按顺序判断：外圈比中心亮 >45 且中心均值 <110 为逆光；否则均值 <75 或欠曝 >55% 为低照度；否则过曝 >18% 为过曝；否则不均匀度 >0.4 为不均匀；其余正常。此为可解释初始规则，受构图影响，不是已训练或已验证的场景分类器，不能从灰度自动识别红外模态。

## 网页算法选择

网页统一提供 Gamma 校正（低照度）、CLAHE（逆光）、Retinex（光照不均）三种增强算法，默认 Gamma。算法旁展示处理侧重；侧重不是场景性能保证。CLAHE 只增强局部对比度，不能恢复饱和丢失的信息；Retinex 估计平滑光照，对极端阴影也可能放大噪声。

网页新建实验默认使用 original/gamma/clahe/retinex，其中 original 是不增强对照组。自适应、曝光补偿、归一化不再作为网页新任务选项；以下实现和 API 兼容仍保留，历史结果按原方法显示，不改写已完成研究证据。

## 独立增强算法

| 方法 | 实现 | 参数与保护 |
|---|---|---|
| Gamma | Y=(X/255)^γ×255，对 RGB/BGR 通道采用相同 LUT | γ∈[0.15,4]，小于 1 提亮，大于 1 压暗 |
| CLAHE | Lab 的 L 通道局部均衡，8×8 网格 | clipLimit∈[0.1,8]；保留 a/b 通道 |
| SSR Retinex | log(Y+1)−log(Gσ*(Y+1))，1/99 分位线性映射，再与原亮度混合 | σ∈[3,100]；strength∈[0,1]；常量图直接返回 |
| 曝光补偿 | gain=clip(target/max(meanY,1),0.5,3)，按强度混合增益 | target∈[40,190]，限制高增益 |
| 光照归一化 | 亮度 2/98 分位映射到 [15,235]，与原亮度混合 | 常量/低动态范围返回原图 |
| Original | 输入副本 | 消融基线、关闭增强 |

Retinex 在最大边 512 的亮度图估计平滑光照，再插值回原尺寸，避免大图巨核的耗时失控；对数采用 +1 防零，输出截断到 0–255 后转 uint8。SSR、曝光、归一化保持 YCrCb 色度分量。色彩空间转换和截断仍可能影响颜色；不宣称绝对无色差。

统一入口：`enhance(image, EnhanceOptions(...)) -> (output, steps)`。独立函数 `gamma/clahe/retinex/exposure/normalize` 可以直接调用，输入不会被原地修改。

## 自适应策略

- 正常：原样保留。
- 低照度：按全局均值计算 Gamma，限制 [0.35,0.9]，随后 CLAHE clip=1.6。
- 逆光：CLAHE clip=2 后保守曝光 target=110、strength=.35。
- 光照不均匀：SSR sigma=30、strength=.45。
- 过曝：Gamma=1.15；饱和像素的信息无法恢复。

策略固定在 `ALGORITHM_VERSION=lumiface-1.0`。实验运行不根据测试标签或最终分数修改策略。未来优化需先在开发/校准数据上决定分支开关，然后新版本冻结后重新测试。手动增强页参数用于探索；批量消融使用 `EnhanceOptions` 默认值，完整参数写入实验配置。

## 检测与对齐

SCRFD 输出框、五点和检测置信度。检测页支持多张人脸；注册和身份确认严格要求恰一张人脸。五点对齐使用 InsightFace 的相似变换 `norm_crop`，得到 112×112 人脸。检测置信度不是身份相似度，也不是概率校准后的人脸真实性。

## 特征与身份决策

ArcFace 每张参考脸提取 512 维特征：u=f/||f||₂。每人模板为各样本归一化特征平均后再次 L2 归一化，原始逐样本特征保留以支持质量检查。相似度 s=uᵀv ∈[-1,1]。

1:1：仅与指定身份模板比较；1:N：全图库取最高相似度。当 s≥τ 才返回确认身份；否则 person_id=null、name=未知身份。候选列表只是诊断信息，不强制归类。

默认 τ=.45 是演示初值。图库规模、成像模态、年龄变化、图像质量都影响分数分布；正式测试必须在独立校准集选阈值。模型指纹与注册模板绑定，切换权重后拒绝复用旧模板。

## 红外限制

当前模型为通用可见光模型。系统能够解码红外灰度图并转三通道执行同样流水线，但这不等同于具备跨模态识别保障。红外标签来自真实采集元信息，不能由低亮度或人工 Gamma 变暗替代。需分别报告 RGB→RGB、IR→IR、RGB→IR 的图库/查询模态；当前 UI 保留来源说明，模态具体协议须写入清单 source 和实验报告。

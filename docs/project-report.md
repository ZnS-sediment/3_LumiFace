# 复杂光照条件下人脸检测增强算法及系统实现

## 本科实训报告初稿

项目名：3_LumiFace。作者、学号、院系、指导教师：待填写。日期：2026-10-17。

## 摘要

人脸系统在低照度、逆光和光照不均匀条件下可能出现漏检与特征不稳定。本实训构建基于 Vue 3 与 FastAPI 的本地 B/S 系统，将可解释的图像光照分析、Gamma/CLAHE/Retinex 等增强方法与 InsightFace 预训练检测识别模型结合，提供身份库、验证检索、未知身份拒识和可复现消融评估。

本项目完成了软件、真实预训练模型联调与两套真实公开数据的固定子集评估。CBSR 主动近红外采用 20 名已知人员图库、70 张校准图和 200 张测试图；Yale B 使用原始 01–10 号的受控光照，50 张校准图与 89 张测试图。原图、Gamma、CLAHE、Retinex、自适应五组均保留逐样本预测、冻结阈值及置信区间。公开数据缺少完整夜间与独立实景证据，红外补光≥95%、强逆光≥90%、综合≥95% 的现场目标不能据此认定达成。

关键词：复杂光照；人脸检测；自适应增强；开放集识别；实验复现。

## 一、研究背景与问题

光照会改变局部纹理、动态范围和可见细节。低照度易使人脸特征信噪比降低，强逆光易导致人脸区域欠曝，局部高亮可能产生不可逆饱和。简单提高全图亮度有可能放大噪声或破坏原有颜色，因此增强是否有效必须通过实际检测与身份决策验证。

本课题采用成熟预训练模型，重点研究增强策略与系统集成，避免本科实训环境下从零训练大型人脸模型。红外与可见光之间存在模态差异，通用 RGB 模型的能力不能直接外推到 IR。

## 二、需求分析

功能需求包含光照质量量化、独立与自动增强、原始/增强检测对比、多样本身份注册、1:1 验证、1:N 检索、阈值控制、未知拒识、数据集导入、五组消融和 CSV 导出。非功能需求包含本地 CPU 可运行、错误提示、可测试、数据访问范围限制、可复现和中文可视化。

考核指标必须区分检测精确/召回、检出条件下识别准确率、端到端身份确认率。漏检在端到端确认率中计失败；未知身份误接受单独统计，防止只报告闭集准确率。

## 三、总体设计

采用 Vue 3 + TypeScript + Vite 构建浏览器客户端，Element Plus 提供表单和表格，ECharts 展示直方图和实验结果；FastAPI 提供 REST API，SQLAlchemy 管理 SQLite，算法层调用 OpenCV、NumPy 和 InsightFace/ONNX Runtime。

系统包含 Person、FaceSample、RecognitionRecord、Dataset、Experiment、ExperimentResult 等实体。注册照片和特征留在本机私有目录；接口不直接公开特征向量。多张照片全部通过单人脸校验后才提交身份，避免半成品注册。

模型固定检测与识别两个任务；默认 CPU，GPU provider 可用时尝试 CUDA。PyTorch 仅作为可选后续研究工具，不属于当前 ONNX 推理的必要依赖。

## 四、算法原理

亮度统计包含均值、直方图、欠曝/过曝比例、标准差、网格均值离散度与 Laplacian 方差。利用中心与外圈亮度差等可解释统计作启发式分类。

Gamma 校正通过幂律改变暗部/亮部映射；CLAHE 在亮度通道局部均衡；SSR 用对数图像减去估计光照，恢复局部反射差异；曝光补偿使用有界增益；归一化使用稳健分位数拉伸。所有输出截断为 uint8，常量图和无效输入有保护。

自适应策略对正常图像不增强，对低照度使用统计 Gamma 与 CLAHE，对逆光采用局部对比度和保守曝光，对不均匀图使用混合 Retinex，对过曝保守压暗。它是待实验优化的初始规则，不声称优于全部单方法。

人脸由 SCRFD 检测，五点对齐到 112×112，ArcFace 提取 512 维特征。每个身份用归一化参考向量均值再归一化得到模板，余弦分数达到固定阈值才确认身份。

## 五、系统实现

前端六个页面对应完整任务链。增强页有参数调节、直方图和下载；检测页同时呈现框、关键点、裁剪和时延；身份管理页支持多图、查询、编辑和删除；身份确认页可切换 1:1/1:N 与增强；实验页支持 ZIP 数据集、后台进度、校准记录、图表、逐样本预览和导出。

后台实验排队执行，启动时冻结图库和参数；标签只用于推理后的计算。模型缺失明确报错，后台失败记录 failed。重启中断任务不会被当作完成。

## 六、测试与实验方案

工程测试分为算法单元测试、指标边界测试、API 集成测试、真实权重联调和浏览器工作流。单元测试中的模型替身仅测试接口逻辑，不用于宣称模型性能。真实模型脚本使用独立临时数据库进行注册、检索、多人脸、消融及删除测试。

研究实验需在 gallery/calibration/test 之间保持独立采集，未知校准/测试身份互斥。现场独立框标注按 IoU≥0.5 一对一匹配；CBSR 独立眼点仅验证预测框包含双眼，Yale 裁剪图仅验证单人脸存在性，这两者不作为 IoU 检测精度；确认率为正确且通过阈值的已知人脸数/全部已知真实人脸数；FAR 为未知误接受数/全部未知真实人脸数。所有综合率按样本计数汇总。

## 七、当前实际结果与限制

全部数值从真实模型保存预测重新计数。协议在推理前冻结、阈值仅由校准集选择；两套来源、使用条款、完整清单和区间详见 docs/real-data-evaluation.md 与 public-benchmark-protocol.md。

| 数据 | 方法 | 已知正确/总数 | 确认率 | 未知误接受/总数 |
|---|---|---:|---:|---:|
| cbsr-nir | 原图 | 94/100 | 94.00% | 0/100 |
| cbsr-nir | Gamma | 95/100 | 95.00% | 0/100 |
| cbsr-nir | CLAHE | 94/100 | 94.00% | 0/100 |
| cbsr-nir | Retinex | 96/100 | 96.00% | 0/100 |
| cbsr-nir | 自适应 | 92/100 | 92.00% | 0/100 |
| yale-b | 原图 | 53/61 | 86.89% | 0/28 |
| yale-b | Gamma | 53/61 | 86.89% | 0/28 |
| yale-b | CLAHE | 53/61 | 86.89% | 0/28 |
| yale-b | Retinex | 53/61 | 86.89% | 0/28 |
| yale-b | 自适应 | 54/61 | 88.52% | 0/28 |

这是分别校准各方法阈值后的主结果，差异同时包含增强和阈值影响。研究报告另给出预先存在的固定默认阈值 0.45 对照，不按测试标签选择参数，也不拿补充结果替换主协议。

近红外研究中自适应并未优于原图，不能概括为增强必然有益。CBSR 未注明夜间环境和跨会话独立性，Yale 是同次短时采集、人工对齐的受控光照；背侧光不等于实景强逆光，环境光不等于夜间。完整原始归档规模也不等于本次已测规模。

工程验证包括 68 项后端测试、前端类型检查/生产构建与真实后端浏览器流程，执行记录见 verification.md。原有公开样例派生图仅保留为功能测试，不与真实公开研究混合统计。

系统增加 Wilson 95% 区间及按人员聚类重采样区间。小规模未知测试中 0 次误接受不能证明总体 FAR 为 0 或≤1%；同源受控条件和预训练身份重叠的不确定性也限制外推。

当前工程边界：本地单机单进程、无生产认证、GPU 与原生 Windows 未实测、场景分类为启发式、RGB→NIR 无验证保证。现场目标判定还需独立会话、硬件/光照日志及足量真实测试，实景模板和审计工具已经提供。

## 八、后续优化与总结

下一步按 field-study-protocol.md 补齐实际夜间与实景逆光/低照度采集，使用 audit_field_data.py 审计标签、会话、重复图与场景证据；用独立校准集验证阈值，再冻结策略测试。若增强引入噪声或使相似度下降，应调整相应分支或保留原图，报告正负结果。红外任务应采用对应模态图库或有验证的跨模态模型，不能只套用 RGB 模型结论。

本实训完成了可运行的研究系统和可复核的评估路径，但研究目标的达成还需要真实数据证据。软件跑通与性能达标是两个不同阶段。

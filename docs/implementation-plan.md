## 决策与限制
- 系统 Python 3.8 不满足要求；使用已有 Anaconda Python 3.12 建立项目独立 .venv。
- 默认 CPU，ONNX Runtime 有 CUDA provider 时自动尝试 GPU；实际 provider 写入实验记录。
- 预训练模型仅启用检测与特征提取，不启用年龄、性别推断。
- 模型缺失返回明确 503；图像增强不依赖模型，可独立使用。
- 真实红外和逆光数据尚未提供，95%/90%/95% 是目标，不是结果。
- 本地项目，不发布至外部网站。源文件、样本与模型保存在本机。

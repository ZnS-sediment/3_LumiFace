## 决策记录

1. 系统 Python 3.8 不满足要求；使用已有 Anaconda Python 3.12 建立独立 .venv，不改变系统解释器。
2. 默认 CPU，通过 ONNX Runtime 执行官方预训练模型；CUDA provider 可用时优先尝试，实际 providers 写入实验记录。PyTorch 为可选研究/诊断依赖。
3. 预训练模型只启用检测和特征提取；模型缺失返回 503，不静默替换模型。增强算法可独立使用。
4. 注册先逐张验证，再一次提交；照片、特征与查询记录可以删除。runtime 不被静态托管。
5. 测试标签只参与推理后计数；测试阶段不调阈值。保存每个方法的参数、图库摘要、模型指纹、数据摘要和逐样本预测。
6. 数据清单绑定注册时间，新建人员表不复用 ID；避免删人后旧标签误指新身份。
7. 本地项目，使用回环监听，不部署到外部站点。

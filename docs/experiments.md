# 实验设计、指标与复现协议

## 任务定义

检测：判断图像中的人脸位置；不涉及身份。识别：对检测到的人脸提取特征并判断身份。人员自动身份确认：从原始图像进入系统开始，成功检测且达到阈值并匹配正确身份，漏检也算失败。

系统同时提供 1:1 验证（指定身份）与 1:N 开放集检索（图库选身份+未知拒识）。批量消融当前评估 **1:N**，不是 1:1 配对 ROC 基准；不得将其 FAR 当作所有成对验证的 FAR。

## 标注与检测匹配

每个真实人脸需身份标签（未知为 null）、匿名 subject 和 bbox。预测按检测置信度从高到低，匹配尚未使用的真实框中 IoU 最大者；IoU≥0.5 判 TP。一个标注最多匹配一个预测，多余预测为 FP，未匹配标注为 FN。多人脸图逐脸统计。

`IoU = intersection_area / union_area`。

## 指标定义

设 TP、FP、FN 为检测计数，K 为所有已知身份真实人脸数，Kd 为已检测到的已知人脸数，C 为正确身份且通过阈值的人脸数；U 为未知真实人脸数，Ud 为检测到的未知脸数，FA 为未知脸被错误接受为图库身份数。

| 指标 | 定义 | 解释 |
|---|---|---|
| 检测精确率 | TP/(TP+FP) | 预测框中有多少为真脸 |
| 检测召回率 | TP/(TP+FN) | 标注人脸中检出比例 |
| 检出条件下识别准确率 | C/Kd | 有检测结果的人脸中身份判断成功比例 |
| 端到端身份确认成功率 | C/K | 包含漏检失败，核心考核指标 |
| 未知身份误接受率 | FA/U | 以全部未知真实脸为分母 |
| 检出条件下未知 FAR | FA/Ud | 同时报告，避免高漏检掩盖误接受 |
| 平均耗时 | Σt/N_images | 增强+检测+特征+图库比较，排除加载/预热/IO |

分母为 0 返回 null，“未评估”；不以 0% 或 100% 代替。无脸背景图产生的误检计 FP；它不属于“未知真实人脸”的 FAR 分母。若关注空场景误接受应另设计按图像计数的指标，不能混用。

各方法 overall 直接汇总逐样本计数，**不得对各场景的比率简单平均**。按场景同时报告 K、U、图像数、TP/FP/FN。UI 主要显示端到端率；条件识别准确率和条件 FAR 可在结果 JSON 中审计。

## 校准与公平对比

1. 划分策略开发集、gallery、calibration、test，明确会话和身份规则。系统不训练模型。
2. gallery 和已知查询必须同一身份但不同采集会话；未知校准/测试身份互斥。避免同一视频邻近帧跨集。
3. 固定模型权重、图库、检测阈值、预处理实现版本。注册模板统一使用未增强参考照片。
4. calibration 同时含已知和未知人脸。分别运行 original/gamma/clahe/retinex/adaptive。
5. 每个方法从实际最高候选分数及严格大于该分数的浮点候选阈值搜索。保留经验 FAR≤目标 FAR 的候选，选已知确认率最高者；并列选较保守的更高阈值。未检出未知人脸仍在 U 内。
6. 记录目标 FAR、观测 FAR、K/U 与阈值。若无可行阈值报错，若缺一类样本拒绝校准。
7. test 只读取冻结阈值，不基于标签调参。校准时的模型、算法版本和图库摘要必须与当前一致。
8. 支持另一对照协议：所有方法使用相同手动阈值，以隔离增强本身影响；此结果标记“探索性”，不自动判定达标。

独立校准后的各方法阈值不同，解释为“相同 FAR 校准目标下的比较”；固定共同阈值解释为“同一决策阈值下的消融”。报告必须说明所用协议，不混写两者。

## 目标验证

- 红外补光目标 C_IR/K_IR≥.95，必须有真实红外采集和明确图库/查询模态。
- 强逆光目标 C_backlight/K_backlight≥.90，需真实强逆光场景标注。
- 综合目标 C_total/K_total≥.95，并覆盖 normal、low_light、backlight 三场景。

只有真实 test 数据、来自真实校准集的冻结阈值、所需场景有已知样本时才报告本测试集是否达到目标；其他场景为“未评估”或“探索性结果”。最小样本数检查仅为 >0，故界面“达到目标（仅本测试集）”不等于统计可靠性或普遍泛化。正式答辩建议每种目标场景至少数百次独立采集，报告置信区间及人物/会话级重采样结果，不能用大批近重复帧人为放大样本量。

95% 的置信区间可采用 Wilson：

`center=(p+z²/(2n))/(1+z²/n)`；`half=z*sqrt(p(1-p)/n+z²/(4n²))/(1+z²/n)`，z=1.96。独立二项假设不适合强相关连拍，必要时按身份或会话 bootstrap。当前界面未自动计算聚类置信区间，需报告阶段补充。

## 已运行与未运行

- 已运行算法/API 测试与真实权重的公开样例功能联调，见 verification.md。
- 功能联调使用 3 个已知同源派生查询和 1 个未知样例，bbox 为手工近似框，real_capture=false。5 组真实推理结果和耗时保存在 experiments/results/smoke-real-model.json/.csv。

- 不能根据此极小样例得出增强有效性结论。若未来增强使确认率下降，应保留负向结果并仅用开发/校准数据修改策略。

## 复现记录

每次任务保存数据清单摘要、source/license/split、图库模板摘要及编号、模型内容指纹、依赖版本、Python/OS/CPU 信息、ORT providers、增强参数、检测输入/阈值、校准编号、阈值、完成时间、每样本预测、计数与时延。为数据最小化不复制完整特征到实验表；复现时需保留原图库及授权数据。删库/换权重后旧结果可审阅，但不能假称完全复现。

## 真实公开基准补充

2026-10-17 已接入完整的 CBSR NIR 归档与原始 Yale B 01–10 的公开裁剪研究镜像。运行前冻结固定子集、校准后冻结阈值、再运行测试，详情见 public-benchmark-protocol.md。实际完成后以 real-data-evaluation.md 和 experiments/results/real-*/summary.json 为准，旧的四张派生图功能验证不与真实基准混合统计。

系统增加场景证据门槛与真实区间：Wilson 区间基于二项近似；按人员聚类的 bootstrap 保留同一人员的查询相关性。重采样仅用于真实观测结果的不确定性估计，不生成任何人脸分数。相同会话相关性、未核实的预训练身份重叠仍须在报告中说明，区间不能弥补不匹配的采集场景。

CBSR 的独立真值只有眼点，定位按包含两个眼点匹配；Yale 紧裁剪输入按单人脸存在性评估。两者的定位数值均不可冒充 IoU 检测指标。现场目标仍需独立会话和相应真实场景证据，参考 field-study-protocol.md 与自动审计脚本。

## 网页多图测试

可直接在实验评估页选择多张图片或按姓名分目录的查询集，无需制作 ZIP。逐图确认真实身份后，比较不增强与所选算法，完成后自动更新本轮评估，历史实验保留；刷新页面默认显示最近一次。新增 LFW 120 人、600 张照片的数据包和操作详见 [多图识别测试](multi-image-evaluation.md)。正式标注 ZIP 和独立校准流程继续保留。

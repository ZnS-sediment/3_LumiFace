# 界面可读性调整

日期：2026-10-17。

- 改为深色分组导航、白色工具栏与内容区、浅灰页面背景、深色正文；蓝色用于主要操作，绿色用于成功状态。
- 删除独立的 L 图标；品牌仅保留纯文字名称。去掉宣传式首页介绍与快捷卡片，改用实际最近实验列表、模型状态、功能入口和评估步骤。
- 正文、表格和表单使用 14px 字号，辅助说明主要为 12–13px。加深表头、空状态、上传提示、通知、身份确认状态和按钮文字。
- 图表图例、坐标文字及数据线同步加深；小屏对比图纵向排列。

## 实际验证

- Vue TypeScript 检查与 Vite 生产构建通过。
- 既有真实后端的两项 Playwright 流程通过，覆盖增强、检测、注册、身份确认、实验、真实报告切换与下载，并核对创建实验后首页任务记录及模型状态。
- 六个页面的桌面/390px 手机状态和注册弹窗，共 13 个状态、733 处直接文本通过颜色对比检查，未出现页面横向溢出或页面 JS 错误。普通文字按 4.5:1，大字号按 3:1 检查；不可见内容、禁用控件和装饰图标不计入。
- Canvas 图表不属于 DOM 文本对比检查，另通过主题颜色配置及截图检查刻度、图例和曲线。此检查不是整站无障碍认证。

现有开发服务器刷新页面即可加载新样式；缓存未更新时使用 Ctrl+F5。业务数据、模型与研究成绩未作修改。

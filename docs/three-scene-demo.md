# 三类光照演示图片

新包：`datasets/att_lighting_three_scenes.zip`。网页“身份库管理 → 批量导入身份 → 下载三类光照演示包（40 人）”。后端更新下载目标后需要重启；旧的两个演示 ZIP 与旧研究报告继续保留。

解压后的结构：

```text
att_lighting_three_scenes/
├── gallery/                         # 40 人，每人 3 张清晰参考；只导入这个文件夹
├── query/
│   ├── 01_逆光_CLAHE/                # 40 人 × 7 张 = 280 张
│   ├── 02_光照不均_Retinex/          # 40 人 × 7 张 = 280 张
│   └── 03_低照度_Gamma/              # 40 人 × 7 张 = 280 张
├── reference/正常光照/              # 同一张源图的正常光照对照，共 280 张
├── unknown/                        # 三类未知人员示例，共 6 张
├── 三类光照对照.png
├── 使用说明.txt
├── SOURCES.md
└── protocol.json
```

三类目录下都按 ATT_s01–ATT_s40 再分人员。相同人员、相同文件编号对应同一源图，例如三个目录的 ATT_s05/06.png 可以横向对照。每类包括源文件 04–10；04–05 保留为校准角色，06–10 保留为测试角色。

这些是待增强的模拟输入，目录中的算法名表示建议选择的增强方法，不是已执行增强的输出。在增强实验室上传相应照片，选择对应算法，再点击“分析并增强”。结果图可以单独下载。推荐方法不保证提高每张照片的余弦相似度；网页自动光照标签可能与生成目录不同，因为它使用启发式规则。

光照不均为新生成的平滑方向照明场，保留人脸姿态、五官和图像几何；没有将 pseudo_infrared 改名。低照度、逆光沿用旧模拟包的同一图片；清晰图库与原始 AT&T 演示包逐字节一致，已有身份无需重新注册。

所有特殊光照均为软件模拟。旧报告不评估新增光照不均数据，不能直接套用旧准确率；本包也不是实验评估页直接导入的标注 ZIP。

脚本直接读取保留的两个 ZIP，无需在 WSL 重新解压大目录，也不会访问正式身份数据库：

```bash
cd /home/zns/3_LumiFace
.venv/bin/python scripts/prepare_three_scene_demo.py
```

# 网页批量导入身份与公开演示数据

日期：2026-10-17。

## 网页操作

打开 http://localhost:5173，进入“身份库管理”，点击“批量导入身份”。

1. 点击“选择照片根目录”，选择一个含多个人员子文件夹的目录。不要选择单个人员目录，也不要选择包含 gallery、query 的整个数据包上级目录。
2. 预览每人的姓名/身份标签、照片、数量。文件夹名作为显示姓名；身份列表的编号从 1 连续显示，删除或搜索后重新排列。数据库内部 ID 保持稳定，供查询和删除使用。每批最多 200 人，每人 1–10 张 JPG/PNG，每张最多 12 MB。
3. 无需设置数据批次，选择有效目录后即可开始导入；统一备注可以留空。每个人的本次注册自动记录内部来源编号，报告保留该编号，不证明照片来自独立采集会话。单人注册也无需填写会话编号。
4. 必填项后用红色“（必填）”标注，统一备注不标注“（选填）”。缺少目录时，点击“开始导入”会弹出具体缺项且不提交请求。页面顺序调用现有注册接口，逐人进行真实检测、特征提取和入库，显示已处理数及逐人结果。
5. 同名人员跳过，不覆盖或追加已有照片。某人的任一照片不符合要求，则该人整组失败，其余人员继续。
6. “停止后续导入”会等待正在处理的人员完成后停止。已成功人员保留，不回滚整批。服务异常或请求结果不确定时标为“待核对”并停止，不自动重试；先核对身份库后再重新选择。
7. 下载 JSON 导入结果。关闭窗口后身份列表会刷新；查询框清空后显示新人员。处理结束后，“选择照片根目录”和“重新选择”均可直接打开目录选择窗口；重新选择同一目录也会建立新的预览，已同名人员仍跳过。取消选择保留当前结果，正在导入时不能更换目录。

导入图片前请人工确认同一文件夹内都是同一个人。此功能按标签注册，不是自动聚类，也不会从照片推断真实姓名。

- [剑桥大学托管的来源与说明](https://www.cl.cam.ac.uk/research/dtg/attarchive/facedatabase.html)

- s1–s40 是源数据的身份编号，不提供真实姓名。导入版显示为 ATT_s01–ATT_s40。
- 原始归档 SHA-256：509d763bd2276aa054d260d7f1000e8be212738134f2f83d8ff13bc2adf1c8ec。

若 Windows 浏览器无法读取 WSL 共享路径，请在批量导入窗口点击“下载 AT&T 演示数据包（40 人）”。浏览器会将 `att_faces_demo.zip` 下载到 Windows。使用 Windows 的“全部解压缩”，例如解压到 `C:\LumiFace-demo`，然后选择实际解压出的 `gallery` 文件夹。常见结构为：

```text
C:\LumiFace-demo\att_faces_demo\gallery
```

选中 `gallery` 文件夹本身即可，应显示“已读取目录：gallery/”和“40 人 · 120 张照片”。查询照片位于同级的 `query`。只选择目录不会入库，还需点击“开始导入”，无需填写数据批次。数据包只包含公开 AT&T 样例、匿名身份标签和来源说明，不包含业务身份库。

WSL 内的原件仍保留在上述 Linux 目录。此前给出的共享路径如下，但它是否能打开取决于 Windows 对 WSL 分发版的访问及浏览器目录选择器；若无法读取，请使用下载后解压到 Windows 磁盘的数据：

```text
\\wsl.localhost\Ubuntu-20.04\home\zns\3_LumiFace\datasets\att_faces_demo\gallery
```

注册后，在“身份确认”上传 query/ATT_s01/04.png 等查询照片。目标身份选择 ATT_s01；也可以直接做 1:N 检索。全部 40 人入库后，这 40 人都属于已知人员；未知拒识需要其他未注册人员照片，例如项目 work/hopper.png。

## 图像准备与适用范围

原始图像为 92×112 灰度 PGM，现代检测器对紧裁剪输入可能漏检。导入版无损转 PNG，统一在每张四周增加 64px 灰度 128 的上下文边框，得到 220×240；人脸像素保持不变。该适配在查询推理前固定，没有生成新的人脸，也没有按查询成绩筛掉照片。

图库固定使用源文件 1–3，查询固定使用 4–10。不同文件不等于独立采集会话，本包不能作为 95%/90%/95% 实景验收证据。它只有身份标签，没有独立人脸框标注，也不是实验页直接导入的标注 ZIP。

原始 400 张 PGM 及来源页保存在 datasets/raw/att-faces，未写入源码包。复现整理：

```bash
cd /home/zns/3_LumiFace
.venv/bin/python scripts/prepare_att_faces_demo.py
```

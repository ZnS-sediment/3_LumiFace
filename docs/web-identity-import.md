# 网页身份导入

进入“身份库管理 → 批量导入身份”，有两个独立链接：“下载原数据包（120 人）”和“下载新数据包（280 人）”。两包没有重复身份，可以任选一包或一起注册。下载到 Windows 后解压。

1. 点击“选择照片根目录”。在本机 Windows + WSL 环境会打开 Windows 系统目录窗口；选择 `lfw_120_lighting/gallery`（120 人、240 张）或 `lfw_280_new_lighting/gallery`（280 人、560 张），每个人一个子文件夹。系统先返回完整路径与人员清单，无需复制粘贴，也无需再选一次。
2. 页面在“已读取目录”旁显示完整盘符或 WSL/网络共享路径、人数、照片数；长路径自动换行。路径来自系统选择窗口，取消选择保留原内容，重新选择自动更新。姓名来自人员文件夹，无需填写批次；备注可以留空。
3. 点击开始导入。同名人员跳过，任意参考照片没有恰好一张人脸时，该人整组失败，其他人员继续。停止操作在当前人员处理后生效。全部注册成功或同名跳过后，窗口自动关闭并提示数量；失败、待核对或手动停止时保留结果。
4. 窗口保留结果时可下载逐人报告，报告包含 root_directory 完整路径。系统目录选择每人 1–10 张、单张不超过 12 MB，每次不超过 500 人、总照片不超过 100 MB。
5. 导入窗口只保留系统目录选择，不提供浏览器目录选择。系统选择不可用时会显示原因并禁用选择按钮；请在本机 Windows/WSL 环境启动后端后重试。

系统选择仅支持运行后端的本机 Windows/WSL；使用 Windows 原生 Common Item Dialog，无需安装插件。首次启动服务时会用系统自带 C# 编译器生成并缓存目录助手，后续点击直接启动；目录窗口自身置顶显示，避免被浏览器遮挡。助手内嵌 PerMonitorV2 高 DPI 清单，在高缩放屏幕按实际 DPI 绘制，避免被系统位图放大；旧系统使用兼容声明。修改助手源码或清单都会重新生成缓存。后端只读取系统窗口中明确选中的目录，不接收网页传入的任意磁盘路径。选择与预览不注册身份、不写入源照片，只有“开始导入”才逐人读取原照片并进行注册。选择目录时不再一次读取全部照片或传输 Base64；缩略图按需加载，单张预览最长边 96px。窗口关闭或重新选择后释放旧凭证；服务重启或长时间未操作后需重新选择。

原 120 人包保持不变；新 280 人包排除原包全部人员，并保留所有查询图片。已经导入此前混合 400 人包的人员会因同名被跳过，无需先删除身份。查询图片在 `query` 下，按正常光照、逆光、光照不均、低照度分目录；这些图片用于增强或测试，不用于注册。

删除身份只清理导入生成的注册副本、特征和关联查询记录，下载包与源照片保留。详细的目录、来源和场景说明见 [多图测试与光照数据](multi-image-evaluation.md)。

## 命令行批量导入

需要自动化时使用 `scripts/batch_import_faces.py`，目录仍为“根目录 / 人员姓名 / 照片”。先预检，再使用 `--apply` 实际注册：

```bash
.venv/bin/python scripts/batch_import_faces.py /path/to/gallery --capture-prefix enroll-session-1
.venv/bin/python scripts/batch_import_faces.py /path/to/gallery --capture-prefix enroll-session-1 --apply --report work/import-result.json
```

采集前缀表示真实注册会话，不与校准或测试混用。脚本对同名人员跳过，连接中断时标记 uncertain 并停止；先核对身份库再重跑。网页无需填写该前缀。

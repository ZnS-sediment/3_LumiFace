# 多图识别测试与新增 LFW 数据

## 网页操作

更新后重启后端，刷新网页，打开“实验评估”，顶部即为“多图识别测试”。

1. 先在“身份库管理”注册参考照片。测试使用另外的查询照片；系统会拦截与注册照片像素相同的图片。
2. 点击“选择多张图片”，可一次选多张 JPG/PNG；或点击“选择查询目录”，读取整个目录及其子目录。每次最多 500 张、单张 12 MB、合计 100 MB。
3. 按 `query/人员姓名/照片` 存放时，自动匹配身份库姓名。三类模拟包也支持从目录识别低照度、逆光、光照不均；均可逐张修改。未匹配到人员时保留“待标注”，不会自动当作未知身份。
4. 平铺图片可使用“统一设置真实身份 → 应用到全部图片”。真正未注册的人员应选择“未知身份（不在身份库）”。不要用系统预测的身份作为真实标签。
5. 默认只测“不增强”，也可以勾选 Gamma、CLAHE、Retinex，进行同一批照片的算法对比。选择阈值，点击“开始多图测试”。
6. 页面自动显示本轮进度和完成结果：各方法的正确识别率、正确数与总数、无人脸/多人脸数量、未知误接受率、分场景结果及每张图的真实身份、预测身份、余弦相似度与判定。支持 CSV 导出与图片对比。
7. 每次点击开始都会保存新的实验记录；完成后自动显示新一轮结果，历史记录保留。刷新页面默认选择最近一轮。正在运行的任务不重复提交。

正确识别率使用全部已知身份图片作为分母，漏检、拒识、认错、多张人脸都不能算识别正确。未知身份另统计误接受率；只测试未知人员时，已知正确率显示“未评估”。统计口径为每图单人身份确认，不代表有独立框标注的检测定位准确率。手动标签、阈值和派生照片不能证明 95%／90%／95% 实景目标达标。

多图测试复用现有实验任务、图库快照、增强、检测和 ArcFace 匹配流程；不向正式身份库自动增加人员。删除多图实验时清理该实验生成且未被其他实验引用的测试图片副本，下载的数据包和身份库保留。

## LFW 扩充数据包

本机文件：`/home/zns/3_LumiFace/datasets/lfw_120_demo.zip`。

网页下载入口位于“实验评估 → 多图识别测试”底部，以及“身份库管理 → 批量导入身份”，名称为“下载 LFW 扩充数据包（120 人）”。下载由本机 WSL 后端提供，Windows 浏览器下载并解压后使用。

```text
lfw_120_demo/
├── gallery/LFW_人员姓名/    # 120 人，每人 2 张，共 240 张；注册使用
├── query/LFW_人员姓名/      # 相同 120 人，每人另 3 张，共 360 张；测试使用
├── protocol.json
├── provenance.json
└── 使用说明.txt
```

原始数据来自 scikit-learn 使用的 LFW funneled 镜像。先按姓名字典序选择前 120 个至少有 5 张照片的人员，再按文件名排序取前 2 张注册、后 3 张查询。原始照片含外围背景人脸，直接导入会被单人脸检查拦截，因此所有图统一裁剪中心区域 `x=65:185、y=55:210`，加 64 像素灰色边框，输出为 248×283 PNG；保留该区域内的人脸像素，不使用 AI 重绘，不按查询识别分数筛选。逐图原始来源、原始摘要与输出 SHA-256 均保存在包中。该裁剪适配的结果不等同于原始全图性能。

原始归档 SHA-256：`b47c8422c8cded889dc5a13418c4bc2abbda121092b3533a83306f90d900100a`。

- [scikit-learn LFW 数据说明](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_lfw_people.html)
- [scikit-learn 中的下载地址与固定摘要](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/datasets/_lfw.py)

先下载解压，再将 `gallery` 导入身份库，最后在多图测试选择 `query`。原有 AT&T 40 人可以继续保留；此包另外提供 120 个姓名标签，共可演示 160 个身份。部分参考图可能无法通过单人脸检查，应查看导入报告处理，不把未导入人员误标为已知。图片版权属于原权利人，保留数据来源，仅作本地课程研究演示。LFW 缺少可靠的独立采集会话、实景照明标签和检测框；预训练模型可能使用过这些人物或图片，不将演示结果当作无污染的泛化验收。

复现下载整理：

```bash
cd /home/zns/3_LumiFace
.venv/bin/python scripts/prepare_lfw_demo.py
```

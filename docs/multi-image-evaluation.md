# 多图测试与光照数据

## 页面分工

- 图像增强：单图处理、增强前后预览、结果下载。
- 人脸检测：一次检测、一张标注结果、人脸裁剪；可以开启检测前增强。
- 身份确认：单图 1:N 或 1:1 匹配，显示确认结果和相似度。
- 实验评估：唯一的批量评估入口，按“新建测试、测试结果、历史记录”切换。每次测试独立保存，完成后自动切换到结果；刷新结果页会恢复当前记录。

实验评估不再同时展示第二套 ZIP 创建表单、历史研究对比面板、图表和重复统计区。带标注 ZIP、独立校准及既有研究记录仍可通过后端 API 和研究脚本读取，不与新建网页测试混在一起。

## 操作顺序

1. 身份库导入 `gallery`。每个人的文件夹名是身份标签。
2. 单图处理时，在三类特殊光照目录任选一张，选择括号标明的建议算法，观察预览并下载结果。算法侧重不保证每张图相似度提高。
3. 实验评估 → 新建测试 → 选择查询目录；选择 `query` 内的一个场景目录（原包每次 360 张，新包每次 840 张），不要选择整个 query。
4. 文件夹名自动匹配已注册身份，特殊光照目录名自动匹配场景。未匹配项须手动确认；不会把待标注人员自动当作未知。平铺图片可统一设置真实身份。
5. 勾选“不增强”和需要比较的方法，直接开始多图测试，系统使用固定校准值。
6. 自动切换“测试结果”，查看正确数/已知总数、正确率、未知误接受、逐张判定。汇总场景可切换；逐图表保留所有方法和场景记录。
7. “新建测试”用于下一轮，“历史记录”用于回看或删除。不会覆盖上一轮数值。

每次最多 1,500 张，单张不超过 12 MB、合计不超过 100 MB。已注册参考图和同批重复像素图会被拦截。正确率分母包含所有已知图片，漏检、拒识和认错均不能算正确。多脸图片逐脸识别，只要任一已确认身份编号等于图片真实身份，就算该图片正确；单脸仍须精确匹配且通过阈值。未知标签的多脸图片有任一已确认身份即算一次误接受。未知身份另统计误接受率。

## 来源与处理

原始 LFW 来自 [scikit-learn 使用的公开镜像](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.fetch_lfw_people.html)，原始归档 SHA-256 为 `b47c8422c8cded889dc5a13418c4bc2abbda121092b3533a83306f90d900100a`。先按姓名字典序选择 400 个至少有 5 张照片、且前 2 张参考图能各检测到一张人脸的人员，再排除原包的全部 120 人，得到 280 人新包。每人另 3 张全部作为查询，不按查询识别成绩筛选。

基础包统一裁剪中心区域 x=65:185、y=55:210，加 64 像素灰色边框，以排除外围背景人脸。新包保留注册和正常查询字节，三种特殊光照仅对原查询照片施加固定曝光和空间照明场：逆光为亮背景暗人脸，光照不均为方向阴影，低照度为整体曝光下降。不生成新的人脸，不改变图像几何。

特殊光照图片是**软件模拟的待增强输入**，并非真实采集、并非增强结果。正常图与三个变体属于同源数据，不可当作独立采集会话或跨校准/测试划分。LFW 可能用于过预训练，不能据此声明独立实景目标达标。图片版权属于原权利人，仅用于本地课程研究演示。

网页多图测试对每张图片分别自动计算增强参数，并使用原图与增强特征融合进行识别；仍可选择不增强与三种增强算法。逐图结果保留实际参数，历史回放使用当时冻结的参数。

历史记录右上角可切换编号升序或降序，浏览器记住排序选择。每条已完成或失败的测试可点击“重命名”，名称为 1–100 字，保存后历史记录与结果页同步更新，刷新仍保留；正在运行的测试需等待结束后改名。改名不改动图片、原始数据清单、参数或识别结果。

页面不再显示判定阈值；新测试统一采用预置校准值，实际数值仍保存在记录内供复现，历史结果不自动重算。汇总下方单独展示错误类型统计。按方法显示实际出现的未检测到人脸、已知身份被拒识、识别错误、误接受未知身份及数量；历史单脸协议中的“检测到多张人脸”仍按原结果显示；无错误或无该场景图片时分别说明。统计覆盖整次测试并随汇总场景切换，历史测试无需重跑。电脑端分栏，手机端纵向排列。

新建测试时可以填写“测试名称”，不属于必填项。留空沿用原来的“多图测试＋时间”默认名称；填写后在历史记录和结果页显示该名称，之后仍可重命名。名称最多 100 字，提交成功后清空名称输入，方便下一轮测试重新填写。

新任务冻结 `recognition_policy=face-local-v4`、各方法的局部增强/镜像融合权重与 `localization_protocol=image_identity_presence`，不增强组使用相同的多脸判定规则。逐图结果列出全部已确认人名，可展开查看每张脸的身份、相似度与确认判定。多脸命中时总表相似度来自命中真实身份的人脸；详细分数以逐脸列表为准。历史结果和统计不会自动重算，新算法需新建测试后比较。


## 默认身份判定参数

网页不显示或提交阈值，后端统一采用 Glint360K ResNet100 的冻结校准值。
`scripts/calibrate_default_threshold.py` 使用独立开发身份和固定划分的未知身份，按已知正确识别率与未知拒绝率的均衡准确率选取最佳区间中点；选择时不读取留出验证集或网页当前测试的真实身份。
报告见 `docs/default-threshold-calibration.json`。它是公开模拟数据下的默认值，并不保证任意图库的最优值。正常查询图未参与这次光照校准。
扩充包包含部分开发/验证身份，不能把整包结果称为完全未参与校准的独立验证；未知误接受必须另加未注册身份测试。

新旧包身份交集为 0；以合并后的 400 人参考库测试新包全部 3360 张查询图，未调整判定值、未筛掉失败查询图。正常光照用原图，另外三类使用对应建议算法与现有特征融合。

对应模拟低照度 95%、逆光 90%、上述综合 95% 数值目标均达到。红外补光实采没有在该包验证，不将软件压暗等同红外；未知误接受也未由这个全已知身份包验证。
逆光和光照不均的正确数与不增强相同；Gamma 比不增强多正确 1 张。不把这些结果解释为三种增强都带来识别增益。

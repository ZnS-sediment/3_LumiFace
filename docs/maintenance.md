# 代码整理与导入数据清理

本次整理覆盖前端源码、后端应用、测试、数据准备和研究脚本。统一格式，移除未使用导入、重复排序和重复任务包装，合并注册表单与 JSON 下载，补充身份数据类型及 TypeScript 未使用变量检查。历史实验实际引用的算法实现与冻结研究记录保留。

ECharts 改为只注册折线图、柱状图及必要组件，构建中的图表相关 JavaScript 从约 1128 KB 降至 538 KB（gzip 约 379 KB 降至 184 KB）。这是构建产物大小对比，不是首屏延迟实测。

## 清理范围

- 删除已注册身份：清理数据库身份/样本特征、涉及该人的识别记录及系统生成的注册照片副本。
- 下载的演示包、原始照片、查询图、模拟数据、独立实验数据和模型权重保留；不根据姓名猜测原文件位置。
- 清理任务持久化后再删文件，失败返回待处理数，下次删除或后端重启自动重试。启动时仅回收超过一小时、无样本引用的 UUID 注册副本；不会扫描或修改 datasets。
- 数据库提交失败时不删文件；陈旧编号整批拒绝；限制清理路径并保护仍在使用的样本。
- 浏览器关闭导入窗口后释放照片预览引用。浏览器测试改用系统临时目录，结束后删除自己的测试数据库和照片，不在项目中长期积累副本。

后端新增 pending_sample_deletions 表，由启动时 create_all 自动创建，无需手动改库。实际业务数据不参与删除测试。

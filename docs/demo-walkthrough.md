# LumiFace 演示顺序

重启项目后打开 http://localhost:5173，默认进入图像增强。人脸模型在服务启动时自动加载，无需点击加载按钮；网页不显示模型状态。在身份库的批量导入窗口分别下载原 120 人包和新增 280 人包，在 Windows 解压。

1. **注册身份**：选择 gallery，展示目录读取成功、原包 120 人 240 张、新包 280 人 560 张参考图、逐人导入结果。已注册同名人员会跳过。
2. **展示增强**：在 query/03_低照度_Gamma 中选一张图，进入图像增强，使用 Gamma；无需调整参数，展示自动计算的 Gamma、处理预览和下载。再用逆光目录配合 CLAHE、光照不均目录配合 Retinex。特殊光照是软件模拟输入，应明确说明。
3. **展示检测**：人脸检测上传同一张图，点击开始检测，查看标注图和对齐人脸；检测前增强可选。
4. **展示身份确认**：正常查询图做 1:N 检索；1:1 时选择正确身份与其他身份，展示通过和不匹配。再上传多人照片，查看每张脸的裁剪、姓名、分数与未知身份。
5. **展示批量评估**：实验评估 → 新建测试，选一个场景目录，原包读取 360 张、新包读取 840 张图片并匹配身份。选择不增强与对应算法，开始测试；自动跳转测试结果，展示正确数/总数、正确率、逐张失败原因。
6. **展示记录更新**：回到新建测试，换一个场景再运行。在历史记录中回看两轮数据，说明每次独立保存。

请使用 query 作为测试输入，避免拿 gallery 自测。正确率包含漏检、拒识和认错；算法增强可能降低部分图片的相似度，应保留实际负向结果。软件模拟测试不等于 95%／90%／95% 实景目标验收。

详细目录见 [多图测试与光照数据](multi-image-evaluation.md)。

新版增强识别会融合原图与增强特征，避免只用增强图损失身份信息。新建测试中，不增强与增强组使用同样的多脸计分规则；多脸任一已确认身份与标签一致即算该图正确，单脸仍按原规则。旧记录保留旧算法结果，请新建测试比较。不能保证每张图片或每一组数据都提高。
